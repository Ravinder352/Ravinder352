**Comparative ML Study: SVM vs Random Forest for Plant Pathology**

- Implemented and compared SVM and Random Forest classifiers for plant disease classification
- Achieved **92%+ accuracy** on disease detection
- Comprehensive EDA with feature importance analysis
- Production-ready evaluation metrics and confusion matrices
- **Tech Stack:** Python, scikit-learn, OpenCV, Pandas, Matplotlib
